# Creepy Ambience
Creepy Ambience is a Minecraft Mod in NeoForge that introduces unsettling events and ambience to the game. This mod is intentionally non-invasive or capable of griefing the world, but rather introduces random unsettling events that work well in tandem with other horror mods. There is no added mobs, items, blocks, or structures so it's safe to install/uninstall at any point. Includes interactions in both the Overworld, Nether and End.
